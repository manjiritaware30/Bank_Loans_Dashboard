Bank Loans Dashboard 

Project Overview
The Bank Loan Analysis Dashboard is an interactive data analytics project developed using MIS Excel and Microsoft Power BI. The main objective of this project is to analyze bank loan applications, monitor loan performance, and understand important lending trends through interactive visualizations and key performance indicators (KPIs).This dashboard provides insights into loan applications, funded amounts, received payments, interest rates, debt-to-income (DTI) ratios, loan grades, repayment status, and customer home ownership.

Tools & Technologies
 MIS Excel: Data preparation and initial data analysis.
 Microsoft Power BI: Interactive dashboard development and data visualization.
 Power Query: Data cleaning and transformation.
 DAX: Calculated measures and KPI development.

Project Objectives
 Analyze total bank loan applications.
 Track total funded amounts and received payments.
 Monitor good loan and bad loan applications.
 Analyze loan repayment performance.
 Understand interest rates and DTI ratios.
 Identify monthly loan application trends.
 Analyze loan distribution by state, loan term, grade, and home ownership.
